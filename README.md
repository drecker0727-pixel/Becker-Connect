# Becker Connect

Aplicativo Android privado de comunicação para amigos, familiares e grupos.

## Estado atual
Primeiro protótipo Android nativo com tela inicial escura. **Ainda não envia mensagens nem realiza chamadas.**

## Próximas etapas
1. Autenticação por convite e regras de acesso.
2. Mensagens em tempo real.
3. Grupos, áudios e compartilhamento de mídia.
4. Chamadas de voz e vídeo via WebRTC.
5. Notificações e proteção de dados.

## Compilação
GitHub Actions: **Actions → Build Android APK → Artifacts** após uma execução bem-sucedida. O APK é de depuração, não de produção.
